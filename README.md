# Sofa Repair in Chennai — Pepperfry-style furniture marketplace

This build uses the supplied `assets/p001.jpeg` through `assets/p258.jpeg` files.

## Included
- Responsive Pepperfry-style marketplace layout
- Real supplied furniture images
- Working search and category filtering
- Product enquiry modal
- WhatsApp and phone CTAs
- No prices — products show **On Request**
- SEO/GEO/AEO-friendly page content
- CNAME for `sofarepairinchennai.in`

## Important image/variant note
The supplied assets do not contain a reliable product/colour/angle data file. This build therefore never invents side/back views or claims unrelated photos are variants of the same product. Where exact matching variant photos are later identified, they can be added to the product data and the UI can switch them automatically.
